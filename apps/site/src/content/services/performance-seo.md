## Performance is a design decision

Most slow websites are slow because of decisions made in the layout, not the
server. A hero carousel, four web fonts and a chat widget will cost more than any
hosting upgrade can recover.

We treat the performance budget as part of the brief:

- A page weight target that the design has to fit inside
- Self-hosted fonts, subset and preloaded, with metric fallbacks so there is no
  layout shift while they load
- Images resized per breakpoint and served as AVIF/WebP
- No client-side JavaScript unless an interaction genuinely needs it

## SEO groundwork

Search engines reward clarity. We make sure each page has one clear purpose, a
canonical URL, accurate metadata and structured data describing what it is — then
keep the sitemap and feeds in step on every build.
