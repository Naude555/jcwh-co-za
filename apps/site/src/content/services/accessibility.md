## What we check

Colour contrast, focus order, keyboard operability, form labelling, heading
structure, landmark regions, reduced-motion support and screen-reader behaviour
across the main user journeys.

## What you receive

A prioritised report that separates blocking issues from nice-to-haves, each with
the affected selector and a suggested fix — written for whoever is going to make
the change, not for a compliance file.
